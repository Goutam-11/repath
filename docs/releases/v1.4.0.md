# repath v1.4.0

**2026-11-22 — Go, pnpm workspaces, a parser fix, and cross-repo merge.** One
binary over SQLite that answers structural questions about a codebase (*what
breaks if I change this*, *how does A reach B*, *where is the important code*)
for humans and coding agents, with no LLM, no daemon, and no network calls.

## What is new since v1.3.0

- **Go is the fourth language (#80).** A pinned `go-sitter-forest/go` v1.9.4
  grammar, package-directory resolution from `go.mod` (module path plus local
  `replace` targets), receiver typing, interface method calls, struct/interface
  embedding, `main`/`TestXxx` entrypoints, and package-level `const`/`var`
  symbols. repath now dogfoods its own Go source: **281 files / 1,942 nodes /
  3,030 edges**, `impact resolveGo` answers from the graph, and
  `gin-gonic/gin` @ `0f09c3a` indexes **99 files / 1,755 nodes / 2,336 edges**
  in 0.21 s with exact cold/incremental/full parity.
- **pnpm workspace resolution (#79).** A root `pnpm-workspace.yaml` `packages:`
  list is parsed without a YAML dependency, with `*`/`**` patterns, `!`
  negations, and the existing package-entry ladder. Kibana @ `0551196` gains
  **2,156 `ts.import.workspace*` edges over 562 target files** (62,489 → 64,797
  edges), and module boundaries now follow pnpm packages.
- **`export type *` parses (#122).** TypeScript 5.0's type-only wildcard
  re-export was rejected by the pinned grammar. An offset-preserving retry now
  parses it; Kibana's parse failures drop **158 → 52** with no change to edges
  or pending (error recovery had already recorded those bindings). This is a
  truthfulness fix, reported as such.
- **Merged cross-repo index (#88, PLAN decision 25).** `repath merge a/ b/
  --out merged/` copies single-repo artifacts into one deterministic read-only
  snapshot: every file is namespaced per repo, identical nodes are never merged,
  and same-named types that are unique inside each part are linked at 0.45
  (`xrepo.same_type_as`, below the default query floor). `gin` + `echo` merge to
  **214 files / 3,652 nodes / 4,962 edges with 8 cross-repo links**, byte-
  identical on a second run.

The contract is now **25 locked decisions** (PLAN §3) on **schema v6** — no
schema, node-kind, edge-kind, or exit-code change in this release.

## Install

```sh
version=1.4.0
arch=amd64          # or arm64
base="https://github.com/Goutam-11/repath/releases/download/v${version}"
curl -LO "${base}/repath_${version}_linux_${arch}.tar.gz"
curl -LO "${base}/checksums.txt"
sha256sum --check --ignore-missing checksums.txt
tar -xzf "repath_${version}_linux_${arch}.tar.gz"
sudo install -m 0755 repath /usr/local/bin/repath
repath --version    # v1.4.0
```

## Verify

```sh
repath status --json              # indexes lazily; counts + unresolved reasons
repath impact <symbol> --json     # reverse closure
repath map --md --out repath-map  # committable markdown bundle
repath check --fail-on none       # graph-native diagnostics
```

Source builds need Go 1.27+, a C toolchain (cgo), and now the pinned Go grammar
module; release binaries stay Linux amd64/arm64 with cgo.

## Known limitations

- **Go**: implicit interface implementation is not inferred (a call through an
  interface resolves to the interface's own method); build tags are ignored
  (every `.go` file is indexed, so build-tagged duplicates are a visible 0.40
  group); generics are parsed but not inferred; receiver typing is file-local.
- **Cross-repo merge**: links are name-only and below the floor; cross-repo
  `calls` are deferred because pending rows carry no enclosing symbol; a merged
  index is never re-resolved; only `export` and `map --md` read it via
  `--artifact`.
- **Parser**: some valid TypeScript still fails (`parse_ok=0` and counted), most
  visibly `call<typeof import("x")>()`.
- **Resolution**: member calls without a typed receiver stay unresolved by
  design; see `docs/resolution.md` for the ladder and every gap.
- **Scale evidence** is one Linux host per measurement with the recorded load;
  the corpus and budget figures live in `docs/benchmarks.md`.
